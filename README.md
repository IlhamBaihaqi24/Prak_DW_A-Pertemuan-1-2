## 📄 Deskripsi File

### `contohprogram.html` - Profil Mahasiswa
Halaman profil sederhana untuk latihan tag dasar HTML.
- Heading `<h1>` sampai `<h3>`
- Pemformatan teks: `<strong>`, `<em>`, `<b>`, `<u>`
- Baris baru dengan `<br>`
- Karakter khusus (HTML entities): `&lt;`, `&gt;`, `&copy;`

### `quiz.html` - Kontak & Media Sosial
Halaman kontak yang berisi:
- Daftar tautan media sosial (Instagram, GitHub, YouTube) memakai `<ul>` dan `<a>`
- Link email dengan `mailto:`
- Alamat kantor

### `tugasprak.html` - Profil Organisasi IMATIKA
Halaman profil organisasi kampus **IMATIKA (Ikatan Mahasiswa Teknik Informatika)** yang mencakup:
- **Navigasi anchor internal** ke bagian Profil, Bidang Keahlian, Cara Bergabung, dan Kontak
- **2 gambar** dengan atribut `alt` (logo IMATIKA dan Gedung Teknik)
- **3 tipe list**: ordered list (`<ol>`), unordered list (`<ul>`), dan description list (`<dl>`)
- **Link eksternal** (Instagram dan website program studi), serta link **email** (`mailto:`)
- Elemen semantik seperti `<nav>`, `<hr>`, dan `<small>`
